# Устранение неполадок UAV Analytics

## Проблема: Кнопка "Сгенерировать отчет" не работает

### Возможные причины и решения:

1. **Бекенд не запущен**
   ```bash
   # Проверьте статус контейнеров
   docker-compose ps
   
   # Если контейнеры не запущены
   docker-compose up --build
   ```

2. **Ошибка в Docker при запуске**
   ```bash
   # Остановите контейнеры
   docker-compose down
   
   # Пересоберите образы
   docker-compose build --no-cache
   
   # Запустите заново
   docker-compose up
   ```

3. **Проверьте доступность API**
   - Откройте http://localhost:8000 - должно показать `{"status": "Service is running"}`
   - Откройте http://localhost:8000/docs - должна открыться Swagger документация

4. **Проверьте логи бекенда**
   ```bash
   docker-compose logs backend
   ```

5. **Проверьте инициализацию регионов**
   ```bash
   # В логах должно быть сообщение "Инициализация регионов..."
   docker-compose logs backend | grep -i region
   ```

## Проблема: Регионы не отображаются

1. **Проверьте API регионов**
   ```bash
   curl http://localhost:8000/api/regions
   ```
   Должен вернуться список регионов с названиями.

2. **Если регионы пустые, перезапустите бекенд**
   ```bash
   docker-compose restart backend
   ```

## Проблема: Данные не загружаются

1. **Проверьте формат JSON файла**
   - Используйте `test_integration_data.json` как пример
   - Убедитесь, что все обязательные поля заполнены

2. **Проверьте консоль браузера**
   - Откройте Developer Tools (F12)
   - Посмотрите на ошибки в консоли

## Быстрая диагностика

### Проверьте все сервисы:
```bash
# Статус контейнеров
docker-compose ps

# Логи всех сервисов
docker-compose logs

# Проверка API
curl http://localhost:8000/
curl http://localhost:8000/api/regions
curl http://localhost:8000/api/flights

# Проверка фронтенда
curl http://localhost:3000/
```

### Полная перезагрузка системы:
```bash
# Остановка и удаление контейнеров
docker-compose down -v

# Очистка образов (опционально)
docker system prune -f

# Пересборка и запуск
docker-compose up --build
```

## Известные проблемы

1. **Docker Desktop не запущен**
   - Убедитесь, что Docker Desktop запущен и работает

2. **Порты заняты**
   - Убедитесь, что порты 3000, 8000, 5432 свободны
   - Остановите другие приложения, использующие эти порты

3. **Недостаточно памяти**
   - Убедитесь, что у Docker достаточно памяти (минимум 4GB)

4. **Проблемы с правами доступа (Linux/Mac)**
   ```bash
   sudo chown -R $USER:$USER uav-analytics/
   ```
