# Тестирование UAV Analytics MVP

## Пошаговое тестирование интеграции

### 1. Запуск системы

```bash
cd uav-analytics
docker-compose up --build
```

Дождитесь запуска всех сервисов:
- ✅ База данных готова (postgres_data)
- ✅ Бекенд запущен на порту 8000
- ✅ Фронтенд запущен на порту 3000

### 2. Проверка доступности

1. **Фронтенд**: http://localhost:3000
   - Должна открыться главная страница с навигацией
   - Проверьте, что все страницы доступны: Dashboard, Analytics, Flights, Upload

2. **Бекенд API**: http://localhost:8000
   - Должен вернуть: `{"status": "Service is running"}`

3. **API документация**: http://localhost:8000/docs
   - Должна открыться Swagger UI с документацией API

### 3. Тестирование загрузки данных

1. **Перейдите на страницу Upload** (http://localhost:3000/upload)

2. **Загрузите тестовые данные**:
   - Используйте файл `test_integration_data.json` из корня проекта
   - Или скопируйте JSON из раздела "Пример данных" ниже

3. **Проверьте результат**:
   - ✅ Должно появиться сообщение об успешной загрузке
   - ✅ Количество обработанных полетов: 5

### 4. Тестирование Dashboard

1. **Перейдите на Dashboard** (http://localhost:3000/dashboard)

2. **Проверьте отображение данных**:
   - ✅ Всего полетов: 5
   - ✅ Активных регионов: количество регионов с полетами
   - ✅ Средняя длительность: рассчитанная автоматически

3. **Проверьте топ регионов**:

4. **Тест обновления данных**:

   - ✅ Данные должны перезагрузиться

### 5. Тестирование Analytics

2. **Проверьте дефолтные настройки**:

5. **Проверьте сводную статистику**:

### 7. Тестирование API напрямую

Используйте curl или Postman для тестирования API:

```bash
# Проверка статуса
curl http://localhost:8000/

# Получение списка полетов
curl http://localhost:8000/api/flights

# Получение рейтинга регионов
curl http://localhost:8000/api/analytics/rating/regions

# Получение динамики полетов
curl "http://localhost:8000/api/analytics/dynamics?start_date=2024-10-01&end_date=2024-10-02"
```

## Устранение проблем

### Если данные не отображаются:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что бекенд доступен на порту 8000
3. Проверьте логи Docker: `docker-compose logs backend`

### Если загрузка не работает:
1. Проверьте формат JSON данных
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте логи бекенда для деталей ошибки

### Если графики не отображаются:
1. Убедитесь, что есть данные за выбранный период
2. Проверьте настройки фильтров
3. Попробуйте обновить страницу

### Если кнопка "Сгенерировать отчет" не работает:
1. Убедитесь, что бекенд запущен: http://localhost:8000
2. Проверьте, что даты заполнены корректно
3. Посмотрите в консоль браузера (F12) на ошибки
4. Попробуйте перезапустить контейнеры: `docker-compose restart`
5. См. подробное руководство в файле TROUBLESHOOTING.md

## Тестирование новых функций

### 8. Тестирование определения регионов

1. **Проверьте автоматическую инициализацию регионов**:
   - При первом запуске системы должны автоматически создаться тестовые регионы
   - Проверьте API: http://localhost:8000/api/regions
   - Должен вернуться список регионов с названиями

2. **Проверьте привязку полетов к регионам**:
   - Загрузите тестовые данные
   - В списке полетов должны отображаться названия регионов вместо "Не определен"
   - В Dashboard и Analytics регионы должны показываться с реальными названиями

### 9. Тестирование топа регионов

1. **Проверьте новый компонент топа регионов**:
   - На Dashboard должен отображаться улучшенный топ регионов
   - Регионы должны показываться с названиями, а не только ID
   - Должны отображаться проценты от общего числа полетов
   - Должны быть медали для топ-3 регионов

2. **Проверьте обновление данных**:
   - Нажмите кнопку обновления в топе регионов
   - Данные должны перезагрузиться

### 10. Тестирование генерации отчетов

1. **Перейдите на страницу Reports** (http://localhost:3000/reports)

2. **Проверьте настройки отчета**:
   - По умолчанию должен быть установлен период с 01.01.2024 по 01.01.2025
   - При необходимости измените диапазон дат
   - Выберите регион (опционально)
   - Выберите формат экспорта (PDF или Excel)

3. **Сгенерируйте отчет**:
   - ✅ Нажмите "Сгенерировать отчет"
   - ✅ Должен появиться предварительный просмотр с подробной статистикой
   - ✅ Проверьте разделы: сводная статистика, анализ по регионам, анализ по типам БПЛА

4. **Проверьте экспорт**:
   - ✅ Нажмите "Экспортировать"
   - ✅ Должен скачаться файл в выбранном формате (PDF или Excel)

5. **Проверьте кнопку на Dashboard**:
   - ✅ На Dashboard нажмите "Создать отчет" в разделе "Быстрые действия"
   - ✅ Должен произойти переход на страницу Reports

### 11. Проверка API отчетов

Используйте curl для тестирования нового API:

```bash
# Генерация отчета
curl "http://localhost:8000/api/reports/generate?start_date=2024-10-01&end_date=2024-10-02"

# Генерация отчета для конкретного региона
curl "http://localhost:8000/api/reports/generate?start_date=2024-10-01&end_date=2024-10-02&region_id=1"
```
